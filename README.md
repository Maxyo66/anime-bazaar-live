# Anime Bazaar live

Portable playable release of Anime Bazaar, including all six character rework batches.

Open https://maxyo66.github.io/anime-bazaar-live/ to play. Progress stays in your browser. Export your profile from the original game using Share codes and restore it here to move supported profile data. Unfinished runs are not included in profile codes. Automatic friend updates require the original hosted backend and are unavailable on this static host; manual save/friend codes remain supported.

Do not delete the original site or browser data until migration has been checked.
